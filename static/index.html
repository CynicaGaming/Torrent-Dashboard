Step 2 of 4

Protect dashboard access

Choose which network adapters are trusted. Every selected adapter contributes its current subnet, and you can also allow individual IP addresses or CIDRs.

Trusted network interfacesSelect one or more network interface cards. Their current subnets are trusted automatically.
Detecting network interfaces…
Loopback access on the host is always trusted. Trusted interfaces follow their current subnet, so DHCP address changes do not require manual updates. You can also add one IP address or CIDR per line.
Step 3 of 4

Add a download client

Torrent Dashboard connects to qBitTorrent through its Web API. API key authentication is preferred on qBitTorrent 5.2+. Username and password are available for older versions.

Generate it in qBitTorrent → Preferences → Web UI → API key.
Not tested yet
If qBitTorrent runs on the same PC as Torrent Dashboard, keep 127.0.0.1:8080. Remote users connect to Torrent Dashboard on port 8765; qBitTorrent itself does not need to be exposed to the LAN.

Review and finish

Torrent Dashboard will re-test qBitTorrent once more, save the settings, and start collecting torrent status.
